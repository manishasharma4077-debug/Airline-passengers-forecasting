# Airline Passenger Forecasting Using ARIMA and SARIMA

## Project Overview
This project focuses on time series analysis and forecasting of airline passenger numbers using the AirPassengers dataset. It applies ARIMA (AutoRegressive Integrated Moving Average) and SARIMA (Seasonal AutoRegressive Integrated Moving Average) models to analyze historical passenger trends, identify seasonal patterns, and forecast future passenger demand.

## Objectives
- Analyze historical airline passenger data.
- Identify trend, seasonality, and patterns in the time series.
- Perform time series decomposition and stationarity analysis.
- Build forecasting models using ARIMA and SARIMA.
- Compare model performance using forecasting evaluation metrics.
- Visualize historical data and future passenger predictions through a dashboard.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Statsmodels
- Scikit-learn
- Plotly
- Kaggle Notebook

## Key Features
- Exploratory Data Analysis (EDA)
- Time series visualization and decomposition
- Stationarity testing
- ARIMA and SARIMA model implementation
- Future passenger forecasting
- Model performance comparison
- Interactive forecasting dashboard

## Dataset
The project uses the AirPassengers dataset, which contains monthly international airline passenger totals from 1949 to 1960.

## Project Outcome
The project demonstrates how time series forecasting techniques can help identify historical trends and seasonal variations and estimate future airline passenger demand. The dashboard presents the actual passenger data, forecasts, and model comparisons in an easy-to-understand visual format.

## Applications
- Airline demand forecasting
- Passenger capacity planning
- Seasonal travel analysis
- Resource and operational planning

## Conclusion
This project provides practical experience in time series analysis, statistical forecasting, model evaluation, and data visualization. It demonstrates the use of ARIMA and SARIMA for forecasting problems involving trend and seasonality.
